# 8453 — audio reactive stage

Музыкальная WebGL-сцена на React Three Fiber. Свет, bloom, танцпол и центральные
объекты реагируют на реальные атаки kick и clap, а не на случайную громкость
кадра.

## Запуск

```bash
npm install
npm run dev
```

Production-проверка:

```bash
npm run build
```

## Как работает синхронизация

1. После пользовательского клика Web Audio декодирует трек.
2. `src/audio/beatAnalysis.js` параллельно анализирует kick-полосу 35–190 Hz и
   clap/snare-полосу 750–5200 Hz.
3. RMS-огибающие сравниваются с отдельными адаптивными локальными порогами.
4. Локальные максимумы разделяются refractory-интервалом 160 ms, поэтому одна
   бочка не превращается в несколько вспышек.
5. Найденная карта onset-событий синхронизируется с `AudioContext.currentTime`.
6. Каждый impact деформирует сферу, но яркий свет имеет отдельный comfort-limit
   240 ms. Быстрая и медленная огибающие дают заметный импульс без стробоскопа;
   bass/mid/high полосы поддерживают непрерывное движение между ударами.

Сторонний beat-detector не используется: анализ выполняется нативным Web Audio
и одинаково работает после смены трека.

## Основные точки настройки

- Полосы kick/clap и их чувствительность находятся в
  `analyzePercussionOnsets()` в `beatAnalysis.js`.
- Защита от частых световых вспышек: `lastComfortFlash` и `0.24` секунды в
  `Visualizer.jsx`. Сфера при этом продолжает видеть каждый impact.
- Компенсация задержки изображения: `VISUAL_LEAD_SECONDS = 0.025` в
  `Visualizer.jsx`.
- Длина светового импульса: `0.105` и `0.32` секунды в `update()`.

Для автоматической браузерной проверки можно открыть `?autostart=1`. Обычный
режим всегда требует клик — это необходимо из-за browser autoplay policy.
